# v0.2.0 Dirt Banks — area, mobs, and drops

First playable milestone of Part B. Questlines, Root Lash / Dig In, and passives come next.

## Area

Sunny Pasture's east portal now leads to **Dirt Banks** (levels 3–5). Dirt ground, warmer sky, brown hills, rocks and clods. Sheet spawn counts: Burrow Mole ×6, Earth Sprite ×4, Ember Beetle ×4. West portal returns to the pasture. The east path to Meadow Shrine is still closed ("later").

Mobs already had v0.1.3 combat stats (`attack_min`/`attack_max`, XP ×0.72, `anim_speed` 0.5). Movement: mole 15, sprite 19, beetle 16 px/s.
