# v0.2.7 — Paths

The first step of the single-class transition, from `planning/v0.2.7.md`. The character is now the **Hero**, who walks **Paths**. The Warrior Path is the first and only train-able path; the Magician Path tab is ready for v0.2.8. Sheet patch: `scripts/sheet-patches/v0.2.7.py`.

## In plain words

- **Hero.** Every place the player reads "Warrior" now says "Hero" (HUD, character screen, classes tab). The internal id stays `warrior` so the stat formulas and saves are untouched.
- **Paths.** New `paths` sheet tab, and `path_id` / `prev_skill_id` on the skills tab. A skill needs its **previous skill at rank 1+** plus materials. **No level gate.** The old level and STR gates on the six Warrior Path skills were removed. Existing skill quests stay and still gate their skill (The Weight of a Swing, Blood Up, A Crack in the Dirt, Hot Edge).
- **Warrior Path chain.** Power Strike (root) → Earthbreaker → Root Lash, Flame Cleave; Power Strike → Dig In; Power Strike → Rage. No new skills. Recipes are the v0.2.6 tables, which already follow the pacing guide (green early branches, Flame Cleave toward blue), so I did not change them.
- **Paths window (K).** A visual tree per path: nodes joined by lines, family colours (basic gold, Nature green, Elemental orange, a Spirit purple reserved), three clear states (**locked** dashed and grey, **available** glowing, **trained** shows its rank), the cost of the next rank on selection, and tabs per path (Warrior, and Magician as "coming soon"). Dashed **future slots** mark the drawing's open branches (a centre line, Rage follow-ups, parked Soul Guard under Dig In, a Spirit follow-up from Flame Cleave). None are trainable.
- **Equip slots.** Eight slots in three groups: **attack 1–4**, **buff 5–6**, **potions Q / G**. A skill only fits its own group. Icons sit in a fixed box, names are one line. Old saves are sorted into the new groups on load. Potions are bound from the bag with Q or G (it used to be 1–6).
- **Calden's tutorial, The Hero's Paths.** Starts after The Weight of a Swing. Six short pages cover Paths, the Hero, families and essence, the chain, and send the player to Ila for passives. He hands over the exact Power Strike rank 2 materials. Then: open the tree (K), train Power Strike to rank 2, return to Calden. Reward 60 XP, 20 Copper, Monster Essence ×6, Training Scroll ×4.
- **Fixes.** Starting weapon is a class-neutral **Club** (10 × 1.10, same as the Wooden Sword; Stone Club is unchanged and later). The basic attack is a quick **slash** again (not the smash) that reaches 70 px and lands on its impact frame, called from inside the animation. **Pell** shows `!` / `?` for The Dirt Path like the other NPCs. **XP:** Field Mouse 4, Wool Sheep 8. **E toggles** shop, training, exchange, storage and talk windows closed. Quest and window logic otherwise unchanged.

## Judgment calls

- Existing saves keep their Wooden Sword; only new Heroes start with the Club.
- Root Lash and Dig In used to unlock by level; they now follow the chain (Root Lash needs Earthbreaker, Dig In needs Power Strike), so Dig In is available right after the first quest.
- Every node is on the tree from the start, locked until its chain and quest are done (the old "hidden until discovered" rule is gone, since the tree is meant to be readable at a glance).
- I picked **4 attack + 2 buff + 2 potion** slots. Potion keys moved to Q and G.
- Pell's quest marker logic was already correct for The Dirt Path in the code, and a new test confirms `!` when it is available and `?` when the hunt is done. I could not reproduce a missing marker; if you still see one, tell me the exact step.
- Calden's tutorial kit is given when the first conversation ends so the training step is always doable.

## Not in this release

No new skills, no Spirit skills, and no orange tier. The Magician tab reads "coming soon" until v0.2.8.

## Checks

`npm run build` is clean and `npm run smoke` passes with no console errors. New checks cover the tree states, lines and tabs, the equip groups, the chain rule, the tutorial end to end, Pell's markers, E toggling, Hero, Club and the XP values.
